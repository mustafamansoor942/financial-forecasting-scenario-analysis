# Financial Forecasting & Scenario Analysis

## Overview

This project presents a three-year financial forecasting and scenario analysis model developed in Microsoft Excel.

The model uses historical financial information to develop forecasts for FY2026F–FY2028F and evaluates the potential impact of different operating and financial assumptions on revenue, profitability, cash flow, working capital, debt, and free cash flow.

The project demonstrates the integration of an income statement, balance sheet, and cash flow statement into a connected financial forecasting model.

## Project Objectives

- Analyze historical financial performance
- Develop three-year financial forecasts
- Forecast revenue and operating costs
- Model working capital requirements
- Forecast the income statement, balance sheet, and cash flow statement
- Evaluate free cash flow generation
- Analyze debt and cash requirements
- Develop downside, base-case, and upside scenarios
- Assess the impact of changing financial assumptions
- Perform balance sheet and model integrity checks

## Key Findings

The model demonstrates how changes in revenue growth, operating costs, working capital, capital expenditure, and financing assumptions can materially affect forecast profitability and cash generation.

The base-case forecast provides a central view of expected financial performance for FY2026F–FY2028F, while the downside and upside scenarios demonstrate the sensitivity of the business to changes in operating assumptions.

The scenario analysis highlights the relationship between operating performance, free cash flow generation, cash balances, and debt requirements.
